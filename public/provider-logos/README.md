# Email provider logos

Downloaded unchanged from the providers' official sites for identifying email choices in Showrunner:

- `gmail.svg`: https://www.gstatic.com/images/branding/productlogos/gmail_2026/v2/web/192px.svg — linked by https://workspace.google.com/products/gmail/
- `ionos.png`: https://www.ionos.com/newsroom/wp-content/uploads/sites/3/2022/02/LOGO_IONOS_Blue_RGB.png — published at https://www.ionos.com/newsroom/download/logo/ (downloaded unchanged with transparency)

The trademarks and logo artwork belong to their respective owners. “Other SMTP” uses the existing Lucide Mail icon because it represents a protocol, not a particular company.

`gmail.png` is a 192×192 transparent PNG export of the Gmail SVG, rasterized with the project's existing Sharp dependency. No background, recoloring or logo redesign was applied. The wizard serves the PNGs locally.
